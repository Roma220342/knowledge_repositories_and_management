# Специфікація агента Hub-Agent
**Мета:** відповідати на питання працівників і HR про політики, структуру компанії та показники навчання, використовуючи гібридне сховище (KB-пошук ЛР 11/14, граф ЛР 9, семантичний шар OLAP ЛР 12) з обов'язковими цитатами; пропонувати нові знання лише через human-in-the-loop.
**Користувачі:** employee (за замовчуванням), hr, admin. **Межі:** лише дані Hub; без довільного SQL/Cypher; без прямого запису. **Автономність:** рівень 2 — агент самостійно читає та відповідає, але пише лише через propose_fact (ризик → авто/людина/відмова).
## Інструменти (MCP-сервер mcp_server/server.py, маніфест із хешами описів — agent/tool_manifest.json)
| Інструмент | JSON-схема входу | Обмеження | Права | Коли використовувати |
|--|--|--|--|--|
| search_kb | {query:str, k:int≤5, role:str} | role ігнорується в безпечному режимі; карантин ін'єкцій | read | питання про політики/правила |
| get_record | {record_id:str} | ACL за чутливістю | read | перевірка цитати |
| graph_lookup | {question:str} | шаблонний пошук; productivityScore лише hr/admin | read | співробітники, посади, керівники, компетенції |
| metric_query | {metric:enum, by:[str], where:{}, limit≤50} | лише метрики семантичного шару; БД mode=ro; тайм-аут 2 с; розріз за співробітником лише hr/admin | read | агрегати навчання |
| propose_fact | {subject, relation, object, source, evidence, action="add"} | лише add; валідація; ризик | write-proposal | нове знання |
## Політики
Ліміти: ≤ 6 кроків (викликів інструментів), ≤ 6000 токенів контексту, тайм-аут 15 с на виклик. Повторні виклики з однаковими аргументами пропускаються. Журнал: кожен запит → logs/trace_*.jsonl (кроки, виклики, результати, затримки); записи знань → logs/audit_log.jsonl.
Заборонені дії: видалення/зміна записів; прямий запис без propose_fact; довільний SQL/Cypher; виклик інструментів поза закріпленим маніфестом; розкриття системного промпта/паролів; чутливі поля без ролі hr/admin.
Human-in-the-loop: low — авто-запис в оверлей з provenance; medium (конфіденційне джерело, зміна існуючої посади, дублікат) — лише після схвалення людини; high (цикл ієрархії, зміна керівника) — автовідмова.
## Пам'ять
Робоча (контекст запиту; TTL = один запит); епізодична (лише журнал трасування, не повертається в контекст; зберігання 90 днів — припущення); семантична (сховище Hub; зміни лише через схвалення, без TTL); пам'ять сесії між запитами не використовується (захист від забруднення).
